# X Translate

[日本語](README.md) | [English](README.en.md) | [繁體中文（台灣）](README.zh-hant.md) | **العربية** | [Español](README.es.md) | [Português](README.pt.md)

سكريبت مستخدم (Userscript) للترجمة التلقائية على منصة [X (Twitter)](https://x.com/). يتيح استبدال ترجمة Grok الأصلية الرديئة في X بخدمة Google Translate، كما يدعم التكامل مع نماذج ترجمة محلية مثل PLaMo 3 Translate أو خدمات ترجمة خارجية أخرى.

يستخدم السكريبت Google Translate افتراضيًا، دون الحاجة إلى تشغيل نموذج أو إعداد مفتاح API. عند تفعيل خدمة ترجمة خارجية، يحاول السكريبت استخدامها أولًا، ويرجع تلقائيًا إلى Google Translate إذا فشل الطلب.

- ترجمة Grok
  - جودة الترجمة سيئة للغاية، وكثيرًا ما تظهر أخطاء في ميزات مثل الترجمة التلقائية.
- Google Translate
  - يدعم هذا السكريبت الترجمة التلقائية بالكامل. جودة الترجمة عمومًا أفضل قليلًا من Grok، لكن زمن الاستجابة أطول قليلًا.
- التشغيل المحلي لنموذج `plamo-3-translate-0.8b-Q4_K_M`
  - جودة ترجمة جيدة وزمن استجابة منخفض للغاية؛ تظهر الترجمات على الصفحة بصورة شبه فورية.

## الميزات

- **الترجمة التلقائية للمنشورات**: تُترجم المنشورات تلقائيًا عند دخولها نطاق العرض المرئي في المتصفح، دون الحاجة إلى النقر على زر الترجمة الأصلي في X لكل منشور. تشمل المنشورات في الخط الزمني والردود والملفات الشخصية وغيرها.
- **الترجمة التلقائية للنبذة الشخصية (Bio)**: يحاول السكريبت ترجمة النبذات الشخصية غير الفارغة تلقائيًا، وتتولى خدمة الترجمة تحديد اللغة المصدر دون الاعتماد على وسوم اللغة التي توفرها X.
- **التبديل بين النص الأصلي والترجمة**: استخدم `Show translation` / `Hide translation` للتبديل بينهما. يمكن إعادة استخدام ترجمة العنصر نفسه في الصفحة دون إرسال طلب ترجمة جديد عند كل تبديل.
- **استبدال الترجمة الأصلية في X**: يتولى السكريبت التحكم في أزرار الترجمة الأصلية التي يمكنه التعرف عليها، ويضيف أزرارًا إلى المنشورات والنبذات الشخصية التي لا تحتوي عليها. ويدعم كذلك عناصر التحكم الأصلية في ترجمة ملاحظات المجتمع (Community Notes) التي يمكنه التعرف عليها.
- **التصفية حسب اللغة المصدر**: يعتمد على السمة `lang` للمنشور لتجاوز المحتوى المكتوب باللغة الهدف نفسها. كما يتجاوز كلًا من الصينية المبسطة (`zh`) والصينية التقليدية (`zh-TW`) عند اختيار الأخرى. لا تخضع النبذات الشخصية لهذه القاعدة.
- **تخصيص اللغة الهدف**: يوفر قائمة لغات قابلة للبحث، ويستخدم لغة المتصفح افتراضيًا، مع إمكانية استعادة الإعداد الافتراضي في أي وقت.
- **خدمات ترجمة مخصصة**: يدعم طلبات GET / POST وتنسيقات استجابة Google Translate / OpenAI، وأجسام الطلبات المتوافقة مع OpenAI، وأجسام طلبات JSON المخصصة، ومفاتيح API الاختيارية.
- **قائمة اللغات المسموح بها في PLaMo**: عند استخدام PLaMo، لا تُرسل إلى الخدمة الخارجية إلا المنشورات التي تتوافق لغاتها مع القائمة. ويتولى Google Translate معالجة المنشورات ذات اللغات غير المدعومة أو التي تفتقر إلى وسم لغة صالح. يتعرف النموذج تلقائيًا على لغة النبذات الشخصية. يمكن تعطيل هذه القائمة عند التكامل مع خدمات ترجمة أخرى.
- **الرجوع التلقائي إلى الخدمة البديلة**: يحاول السكريبت استخدام Google Translate عند انتهاء مهلة الخدمة الخارجية أو إرجاعها خطأً أو ترجمة غير صالحة أو فارغة. وفي وضع PLaMo، يحدث الرجوع أيضًا إذا كان المحتوى يتضمن حروفًا وكانت الترجمة مطابقة تمامًا للنص الأصلي. ويوفر Google Translate واجهة رئيسية وأخرى احتياطية، مع إعادة المحاولة باستخدام الكشف التلقائي عن اللغة المصدر عند الحاجة.
- **الحفاظ على الروابط والرموز التعبيرية**: يحاول السكريبت الاحتفاظ بالروابط والصور المضمنة (بما فيها الرموز التعبيرية على هيئة صور) وفواصل الأسطر في النص الأصلي. وإذا فقدت خدمة الترجمة العناصر النائبة، تُضاف الروابط أو الصور المفقودة في نهاية الترجمة.
- **التحكم في التزامن والتوافق مع الصفحات الديناميكية**: ينفذ ما يصل إلى 5 مهام ترجمة تلقائية في الوقت نفسه، مع إعطاء الأولوية للمحتوى في أعلى نطاق العرض المرئي. يراقب التغيرات الديناميكية في الصفحة، ويدعم تحميل المحتوى أثناء التمرير والتنقل بين الصفحات، ويتجنب عرض الترجمات القديمة على المنشورات التي تغيرت.

## التثبيت

1. ثبّت مديرًا لسكريبتات المستخدم في المتصفح، مثل [Violentmonkey](https://violentmonkey.github.io/).
2. افتح [X-Translate.user.js](https://raw.githubusercontent.com/zerofdest/comprehension/main/X-Translate/X-Translate.user.js) وثبّت السكريبت باتباع تعليمات المدير. ويمكنك أيضًا استيراد ملف `.user.js` مباشرةً إلى المدير.
3. افتح [x.com](https://x.com/) أو أعد تحميل الصفحة ليبدأ السكريبت في العمل.

يعمل السكريبت فقط على الصفحات المطابقة للنمط `https://x.com/*`. ويستخدم Google Translate افتراضيًا بعد التثبيت دون الحاجة إلى إعدادات إضافية.

## طريقة الاستخدام

### إعداد لغة الترجمة

في صفحة X، انقر على أيقونة مدير سكريبتات المستخدم في المتصفح، وابحث عن **X Translate**، ثم اختر **Set translation language**.

في نافذة `Translation Language` التي تظهر، ابحث عن اللغة المطلوبة واخترها، مثل:

| اللغة | رمز اللغة |
| --- | --- |
| English | `en` |
| Japanese | `ja` |
| Chinese | `zh` |
| Chinese (Traditional) | `zh-TW` |
| Korean | `ko` |

تُعاد الصفحة تلقائيًا بعد اختيار اللغة. انقر على `Reset to browser default` لاستعادة لغة المتصفح الافتراضية.

### عرض النص الأصلي أو الترجمة

عندما تدخل المنشورات والنبذات الشخصية المستوفية لشروط الترجمة نطاق العرض المرئي، يرسل السكريبت طلبات الترجمة تلقائيًا.

| حالة الزر | المعنى |
| --- | --- |
| `Translating...` | الترجمة قيد التنفيذ |
| `Hide translation` | تُعرض الترجمة حاليًا؛ انقر لاستعادة النص الأصلي |
| `Show translation` | يُعرض النص الأصلي حاليًا؛ انقر لعرض الترجمة. إذا لم تكن الترجمة موجودة بعد، يُرسل طلب ترجمة |

إذا فشلت الترجمة، يمكنك النقر على `Show translation` لإعادة المحاولة يدويًا.

### Translator settings

اختر **Translator settings** من قائمة X Translate في مدير سكريبتات المستخدم لإعداد خدمة ترجمة خارجية.

| الإعداد | القيمة الافتراضية | الوصف |
| --- | --- | --- |
| Enable external translator (fallback to Google Translate) | معطّل | يعطي الأولوية للخدمة الخارجية ويرجع إلى Google Translate إذا فشلت |
| Use PLaMo (apply source-language whitelist) | مفعّل | يطبق قائمة لغات PLaMo المصدر المسموح بها على المنشورات؛ يُعطّل عادةً عند التكامل مع خدمات أخرى |
| Request Method | GET | يدعم GET وPOST |
| Translation endpoint URL | `http://127.0.0.1:8001/translate-auto?q=$q` | عنوان API لخدمة الترجمة الخارجية |
| Response Style | Google Translate | اختر التنسيق المطابق لاستجابة الخدمة الفعلية: Google Translate أو OpenAI |
| API Type (لطلبات POST فقط) | OpenAI Compatible | يستخدم تنسيق طلب OpenAI المضمن أو Custom JSON |
| API Key (لطلبات POST فقط، اختياري) | فارغ | إذا لم يكن فارغًا، يُرسل عبر `Authorization: Bearer ...` |
| Model Name (لطلبات POST من نوع OpenAI Compatible فقط) | فارغ | اسم النموذج؛ مطلوب عند استخدام تنسيق الطلب هذا |
| Request Body (لطلبات POST من نوع Custom فقط) | `{"q":"$q","sl":"$slCode","tl":"$tlCode"}` | جسم طلب JSON مخصص |

انقر على `Save` لحفظ الإعدادات وإعادة تحميل الصفحة تلقائيًا، أو `Cancel` لتجاهل التغييرات، أو `Reset defaults` لاستعادة القيم الافتراضية في النافذة ثم `Save` لتطبيقها.

> **ملاحظة:** لا يعمل خيار `Use PLaMo` على تشغيل النموذج ولا يغير لغته الهدف. الخدمة الخارجية معطّلة افتراضيًا، ولذلك لا يستخدم السكريبت سوى Google Translate حتى إذا كان هذا الخيار محددًا.

### التكامل مع خدمات ترجمة أخرى

فعّل `Enable external translator` وعطّل `Use PLaMo`، ثم اضبط طريقة الطلب وعنوان URL وتنسيق الاستجابة وفقًا لمواصفات API الخاصة بالخدمة. لا يؤدي تعطيل قائمة اللغات المسموح بها إلى تعطيل تصفية المنشورات المكتوبة باللغة الهدف نفسها.

#### GET

يجب أن يتضمن عنوان URL العنصر النائب `$q`، مثل:

```text
http://127.0.0.1:8001/translate?q=$q&sl=$sl&tl=$tl
```

هذا مثال على تنسيق واجهة عام، ولا يعني أن جميع الخدمات تقرأ `sl` و`tl`.

| العنصر النائب في URL | القيمة البديلة |
| --- | --- |
| `$q` | النص المطلوب ترجمته |
| `$sl` / `$slCode` | رمز اللغة المصدر؛ أو `auto` إذا كانت غير معروفة |
| `$tl` / `$tlCode` | رمز اللغة الهدف |

تُرمّز العناصر النائبة في عنوان URL تلقائيًا بترميز URL، ولا يُسمح بوجودها إلا في المسار أو معاملات الاستعلام.

#### POST: OpenAI Compatible

على سبيل المثال، للتكامل مع خدمة تدعم تنسيق OpenAI Chat Completions والاستجابة على هيئة كائن JSON:

| الإعداد | مثال |
| --- | --- |
| Request Method | POST |
| Translation endpoint URL | `http://127.0.0.1:8080/v1/chat/completions` |
| API Type | OpenAI Compatible |
| API Key | وفقًا لمتطلبات الخدمة؛ يمكن تركه فارغًا للخدمات المحلية التي لا تتطلب مصادقة |
| Model Name | اسم النموذج الذي توفره الخدمة فعليًا |
| Response Style | OpenAI |

ينشئ السكريبت تلقائيًا رسائل `system` / `user`، ويطلب من النموذج إرجاع JSON يحتوي على `sentence` و`src`، ويضبط `response_format: {"type":"json_object"}` و`temperature: 0` و`stream: false`. يجب أن تكون الخدمة متوافقة مع حقول الطلب هذه؛ وإذا لم تكن كذلك، يمكن استخدام جسم طلب Custom.

#### POST: Custom

اختر `API Type: Custom`، واكتب كائن JSON وفقًا لمتطلبات خدمة الترجمة، مثل:

```json
{
  "q": "$q",
  "sl": "$slCode",
  "tl": "$tlCode"
}
```

تدعم القيم النصية في JSON المخصص العناصر النائبة التالية، بما في ذلك السلاسل النصية داخل الكائنات والمصفوفات المتداخلة:

| العنصر النائب في جسم الطلب | القيمة البديلة |
| --- | --- |
| `$q` | النص المطلوب ترجمته |
| `$sl` | اسم اللغة المصدر بالإنجليزية |
| `$tl` | اسم اللغة الهدف بالإنجليزية |
| `$slCode` | رمز اللغة المصدر |
| `$tlCode` | رمز اللغة الهدف |

تُفلت المحارف الخاصة في النص تلقائيًا وفقًا لقواعد JSON. يجب أن يتضمن جسم الطلب أو عنوان URL العنصر النائب `$q` في موضع واحد على الأقل.

#### تنسيقات الاستجابة المدعومة

**Google Translate**:

```json
{
  "sentences": [
    {"trans": "你好，世界！"}
  ],
  "src": "en"
}
```

يدعم السكريبت أيضًا تنسيق المصفوفات المتداخلة المستخدم في الواجهة الرئيسية لـ Google Translate، مثل:

```json
[[["你好，世界！", "Hello, world!", null, null]], null, "en"]
```

**OpenAI**:

```json
{
  "choices": [
    {
      "message": {
        "content": "{\"sentence\":\"你好，世界！\",\"src\":\"en\"}"
      }
    }
  ]
}
```

يمكن أن يتضمن `choices[0].message.content` الترجمة مباشرةً على هيئة نص عادي أيضًا. يُضبط تنسيق الطلب وتنسيق الاستجابة بصورة مستقلة؛ فلا يُشترط استخدام Google Translate مع GET أو OpenAI مع POST.

### الخصوصية وقيود الاستخدام

- يرسل وضع Google Translate النص المطلوب ترجمته إلى Google. بعد تفعيل الترجمة المحلية، يمكن ترجمة النصوص التي تستوفي الشروط وتُعالج بنجاح محليًا، لكن المحتوى الذي لا يتوافق مع قائمة اللغات المسموح بها أو الذي تفشل ترجمته قد يُرسل إلى Google. لا يتضمن الإصدار الحالي خيارًا لتعطيل الرجوع إلى Google، وبالتالي لا يُعد وضع ترجمة يعمل دون اتصال بالإنترنت بصورة صارمة.
- يستخدم السكريبت `GM_xmlhttpRequest` للوصول إلى واجهات من أصول مختلفة. لا تستخدم سوى عناوين URL موثوقة عند إعداد الخدمات الخارجية، ولا ترسل نصوصًا حساسة أو مفاتيح API إلى خدمات غير موثوقة. يُخزّن مفتاح API في إعدادات السكريبت لدى مدير سكريبتات المستخدم.
- تبلغ مهلة طلبات الترجمة الخارجية 60 ثانية، ويبلغ الحد الأقصى للترجمات التلقائية المتزامنة 5 مهام. لا تخضع الترجمات التي يبدأها المستخدم يدويًا لهذا الحد الخاص بقائمة انتظار الترجمة التلقائية.
- قد تتغير واجهات Google Translate وبنية صفحات X. لا يُضمن استمرار عمل جميع الميزات في كل الصفحات ولغات الواجهة وإصدارات المتصفحات.

## التشغيل المحلي لنموذج PLaMo 3 Translate 0.8B (موصى به بشدة)

أحدث إنجازات PLaMo 3؛ ليس من المبالغة وصفه بأنه أفضل نموذج ترجمة بأقل من مليار معلَمة، إلا أن جودة الترجمة تختلف باختلاف اللغة المدعومة.

تتوافق إعدادات الخدمة الخارجية الافتراضية في X Translate مع السكريبت التوضيحي [plamo_flusher_bridge.py](plamo_flusher_bridge.py)، الذي يستخدم نموذج GGUF بتكميم `Q4_K_M` من [PLaMo 3 Translate 0.8B](https://huggingface.co/pfnet/plamo-3-translate-0.8b).

PLaMo 3 Translate نموذج متخصص في الترجمة طورته شركة Preferred Networks (PFN)، ويدعم 53 رمز لغة (بما فيها الصينية المبسطة والتقليدية)، بالإضافة إلى السياق ومسارد المصطلحات. يبلغ حجم ملف GGUF الافتراضي نحو 0.57 GB، ويتطلب التشغيل الفعلي ذاكرة إضافية (RAM أو VRAM).

يتولى سكريبت Python تشغيل llama.cpp، وإنشاء تعليمات الترجمة (prompts) بتنسيق PFML3 الخاص بـ PLaMo، وتحويل استجابة النموذج إلى تنسيق متوافق مع Google Translate. ويمكن لعملية تشغيل واحدة للنموذج خدمة X Translate وYoutubeLiveChatFlusher في الوقت نفسه.

```text
X Translate                GET /translate-auto
                                      |
                                      v
                           plamo_flusher_bridge.py :8001
                                      |
                                      v
                           llama-server :8000
                           POST /v1/completions
                                      |
                                      v
                           PLaMo 3 Translate GGUF
```

### 1. تنزيل بيئة التشغيل والنموذج

تستخدم الخطوات التالية Windows مثالًا:

- [Python](https://www.python.org/downloads/): يُنصح باستخدام Python 3.10 أو إصدار أحدث. لا يستخدم سكريبت الربط التوضيحي سوى مكتبة Python القياسية، ولا يتطلب تثبيت حزم خارجية.
- [llama.cpp Releases](https://github.com/ggml-org/llama.cpp/releases): نزّل نسخة Windows تدعم PLaMo 3 Translate، واختر الواجهة الخلفية الملائمة لعتادك، مثل CPU أو CUDA أو Vulkan. فك ضغط الملفات واحتفظ بجميع الملفات اللازمة للتشغيل. وإذا كانت نسخة CUDA تتطلب مكتبات تشغيل إضافية، فنزّلها وفقًا لتعليمات الإصدار المعني.
  - الإصدار الموصى به: [b12359](https://github.com/ggml-org/llama.cpp/releases/tag/b12359).
- [PLaMo 3 Translate 0.8B GGUF (المستودع الرسمي للنموذج)](https://huggingface.co/pfnet/plamo-3-translate-0.8b-GGUF): نزّل [`plamo-3-translate-0.8b-Q4_K_M.gguf`](https://huggingface.co/pfnet/plamo-3-translate-0.8b-GGUF/resolve/main/plamo-3-translate-0.8b-Q4_K_M.gguf).
- سكريبت التشغيل التوضيحي: [plamo_flusher_bridge.py](plamo_flusher_bridge.py).

يُرجى الالتزام أيضًا بترخيص النموذج [PLaMo Community License](https://huggingface.co/pfnet/plamo-3-translate-0.8b-GGUF#license).

### 2. تعديل إعدادات سكريبت Python

افتح `plamo_flusher_bridge.py` في محرر نصوص، وتحقق من المعاملات الثلاثة التالية على الأقل:

```python
LLAMA_SERVER_EXE = Path(r"I:\llama.cpp\llama-server.exe")
GGUF_MODEL_FILE = Path(r"I:\_models\plamo-3-translate-0.8b-Q4_K_M.gguf")

TARGET_LANG = "zh-hant"
```

**تأكد من استبدال مساري الملفين بالمسارين الفعليين على جهازك، واضبط `TARGET_LANG` على اللغة الهدف المطلوبة.** المسارات على محرك الأقراص `I:` مجرد أمثلة؛ ليس من الضروري استخدام المجلدات نفسها.

على سبيل المثال:

```python
LLAMA_SERVER_EXE = Path(r"D:\llama.cpp\llama-server.exe")
GGUF_MODEL_FILE = Path(r"D:\models\plamo-3-translate-0.8b-Q4_K_M.gguf")
TARGET_LANG = "en"
```

مقارنة رموز اللغات الشائعة:

| اللغة الهدف | X Translate | Python / PLaMo |
| --- | --- | --- |
| الصينية التقليدية | `zh-TW` | `zh-hant` (القيمة الافتراضية في Python) |
| الصينية المبسطة | `zh` | `zh-hans` |
| الإنجليزية | `en` | `en` |
| اليابانية | `ja` | `ja` |
| الكورية | `ko` | `ko` |

للاطلاع على قائمة اللغات الكاملة، راجع [التوثيق الرسمي لنموذج PLaMo](https://huggingface.co/pfnet/plamo-3-translate-0.8b-GGUF#supported-languages).

**مهم: عند استخدام الترجمة المحلية، تكون الأولوية لقيمة `TARGET_LANG` في سكريبت Python على إعداد اللغة الهدف في X Translate.** ويرجع ذلك إلى احتمال وجود مشكلات توافق بين رموز اللغات في PLaMo والنماذج الأخرى.\
يستخدم سكريبت Python التوضيحي حاليًا قيمة ثابتة لـ `TARGET_LANG` في نقطتي النهاية كلتيهما، ويتجاهل معاملي الاستعلام الواردين `sl` و`tl`. لا يؤدي تغيير اللغة في المتصفح إلى تحديث اللغة الهدف في Python تلقائيًا. يجب إعادة تشغيل السكريبت بعد تعديل إعدادات Python.

معاملات اختيارية أخرى:

| المعامل | القيمة الافتراضية | الغرض |
| --- | --- | --- |
| `HOST` / `PORT` | `127.0.0.1` / `8001` | عنوان خدمة الربط للترجمة الخارجية |
| `LLAMA_HOST` / `LLAMA_PORT` | `127.0.0.1` / `8000` | عنوان الواجهة الخلفية llama-server |
| `LLAMA_STARTUP_TIMEOUT` | `120` | مدة انتظار تحميل النموذج (بالثواني) |
| `AUTO_CONTEXT` | سياق منشورات X | تعليمات السياق المستخدمة مع X Translate |
| `ENABLE_TRANSLATE` | `False` | تحديد ما إذا كانت نقطة نهاية التكامل مع [YoutubeLiveChatFlusher](https://github.com/ys-j/YoutubeLiveChatFlusher) مفعّلة أيضًا |
| `CONTEXT` | سياق تعليقات جمهور البث المباشر لليوتيوبرز الافتراضيين (VTubers) اليابانيين | تعليمات السياق المستخدمة عند التكامل مع [YoutubeLiveChatFlusher](https://github.com/ys-j/YoutubeLiveChatFlusher) |
| `SOURCE_LANG` | `ja` | اللغة المصدر الثابتة للتكامل مع [YoutubeLiveChatFlusher](https://github.com/ys-j/YoutubeLiveChatFlusher)؛ لا تؤثر على X Translate |

إذا كنت مهتمًا بعرض تعليقات YouTube فوق الفيديو وترجمتها، فراجع قسم [التكامل مع YoutubeLiveChatFlusher](#التكامل-مع-youtubelivechatflusher).

يمكن أيضًا تخصيص `AUTO_CONTEXT` و`CONTEXT` من خلال متغيري البيئة `PLAMO_AUTO_CONTEXT` و`PLAMO_CONTEXT` على التوالي.

فيما يلي أهم إعدادات معاملات تشغيل llama.cpp الافتراضية:

| المعامل | القيمة الافتراضية في المثال | الوصف |
| --- | --- | --- |
| `--n-gpu-layers` | `99` | ينقل أكبر عدد ممكن من طبقات النموذج إلى GPU؛ ويمكن ضبطه على `0` لاستخدام CPU فقط |
| `--ctx-size` | `3072` | السعة الإجمالية للسياق في الخدمة |
| `--parallel` | `4` | عدد فتحات الاستدلال المتزامنة |
| `--temp` | `0` | يستخدم إعدادًا حتميًا لفك الترميز |
| `--n-predict` | `376` | الحد الأقصى الافتراضي لعدد الرموز (tokens) المولّدة |
| `--jinja` | مفعّل | يفعّل دعم قوالب Jinja |
| `--no-prefill-assistant` | مفعّل | يعطّل الملء المسبق لرسالة المساعد (assistant prefill) |

هذه معاملات السكريبت التوضيحي، وليست قيمًا رسمية موصى بها لجميع الاستخدامات. يجب أن تستوعب سعة السياق أيضًا تعليمات PFML3 ومسرد المصطلحات والنص الأصلي والترجمة. قد تتجاوز المنشورات الطويلة سعة فتحة استدلال واحدة أو تبلغ الحد الأقصى للتوليد. يمكنك زيادة `--ctx-size` / `--n-predict` أو خفض `--parallel` بحسب العتاد وطول النص. راجع سجل بدء تشغيل llama-server لمعرفة السعة الفعلية لكل فتحة.

### 3. اختياري: إعداد مسرد المصطلحات

أنشئ ملف `glossary.json` بترميز UTF-8 في المجلد نفسه الذي يحتوي على `plamo_flusher_bridge.py`، مثل:

```json
[
  {"source": "ひなの", "target": "Hinano"},
  {"source": "スト6", "target": "Street Fighter 6"}
]
```

يقرأ سكريبت الربط المسرد عند كل عملية ترجمة، ولا يضيف إلى تعليمات PFML3 إلا المصطلحات المطابقة فعلًا للنص الأصلي. وعند تداخل المطابقات، يعطي الأولوية للمصطلح الأطول، ولا يضيف المصطلح نفسه أكثر من مرة. وتشترك نقطتا النهاية في هذا الملف.

- **يمكن تشغيل السكريبت بصورة طبيعية دون ملف `glossary.json`**، بما في ذلك عند استخدام `/translate-auto` فقط.
- بعد تعديل الملف، يُقرأ المحتوى الجديد عند الترجمة التالية دون الحاجة إلى إعادة تشغيل خدمة الربط.
- يجب أن يكون الملف مصفوفة JSON تتضمن عناصر تحتوي على السلسلتين النصيتين غير الفارغتين `source` و`target`. يؤدي JSON غير الصالح أو عدم كون البنية العليا مصفوفة إلى فشل طلب الترجمة.
- يُستخدم المسرد ضمن تعليمات النموذج، وليس كآلية استبدال نصي إلزامية؛ لذلك لا يمكن ضمان التزام النموذج بالترجمات المحددة في جميع السياقات.

### 4. تشغيل خدمة الترجمة المحلية

افتح CMD أو PowerShell في المجلد الذي يحتوي على سكريبت Python، ونفّذ الأمر التالي:

```bat
py plamo_flusher_bridge.py
```

إذا كنت تستخدم الأمر `python`:

```bat
python plamo_flusher_bridge.py
```

لا حاجة إلى تشغيل llama-server يدويًا مسبقًا. يشغّل سكريبت Python خدمة النموذج تلقائيًا، ويتحقق من `/health`، ويبدأ معالجة طلبات الترجمة بعد أن يصبح النموذج جاهزًا. يتضمن سجل التشغيل الافتراضي معلومات شبيهة بما يلي:

```text
PLaMo model ready (HTTP /health 200).
Japanese endpoint (/translate) is disabled.
Auto -> zh-hant:     http://127.0.0.1:8001/translate-auto?q=$q
Press Ctrl+C to stop both services.
```

يوفر السكريبت افتراضيًا مسارين لـ API:

| URL | اللغة المصدر | اللغة الهدف | الحالة الافتراضية |
| --- | --- | --- | --- |
| `http://127.0.0.1:8001/translate-auto?q=$q` | يتعرف عليها النموذج تلقائيًا | `TARGET_LANG` | مفعّل |
| `http://127.0.0.1:8001/translate?q=$q` | `SOURCE_LANG` (افتراضيًا `ja`) | `TARGET_LANG` | معطّل |

يمكن إجراء اختبار في نافذة طرفية أخرى (يرمّز `curl.exe` النص تلقائيًا بوصفه معامل استعلام في عنوان URL):

```bat
curl.exe --noproxy "*" -G "http://127.0.0.1:8001/translate-auto" --data-urlencode "q=Hello, world!"
```

إذا كانت الخدمة تعمل بصورة صحيحة، فسترجع JSON مشابهًا لما يلي (تختلف الترجمة حسب النموذج والإعدادات):

```json
{"sentences":[{"trans":"你好，世界！"}],"src":"auto"}
```

تشير القيمة `src: "auto"` إلى وضع الكشف التلقائي، وليست رمز اللغة الفعلي الذي اكتشفه النموذج.

أبقِ طرفية Python قيد التشغيل أثناء الاستخدام. اضغط على `Ctrl+C` لإيقاف خدمة الربط وllama-server الذي شغّلته.

### 5. تفعيل PLaMo في X Translate

افتح صفحة X، وانتقل إلى **Translator settings** في مدير سكريبتات المستخدم، واستخدم الإعدادات التالية:

| الإعداد | القيمة |
| --- | --- |
| Enable external translator (fallback to Google Translate) | مفعّل |
| Use PLaMo (apply source-language whitelist) | مفعّل |
| Request Method | GET |
| Translation endpoint URL | `http://127.0.0.1:8001/translate-auto?q=$q` |
| Response Style | Google Translate |

انقر على `Save`. بعد إعادة تحميل الصفحة تلقائيًا، ستُعطى الأولوية لنموذج PLaMo المحلي لترجمة المنشورات والنبذات الشخصية. تأكد أيضًا من تطابق إعداد `Set translation language` مع `TARGET_LANG` في Python.

لا تستخدم `/translate` في عنوان URL هنا؛ فنقطة النهاية هذه مخصصة لترجمة محادثات البث المباشر بلغة مصدر ثابتة، وهي معطّلة افتراضيًا.

### الأسئلة الشائعة

| المشكلة | الحل |
| --- | --- |
| **ترجمة المنشورات الطويلة غير مكتملة** | زِد قيمتي `--n-predict` و`--ctx-size` وفقًا لمعلومات Token usage المعروضة في نافذة CMD الخاصة بـ `plamo_flusher_bridge.py` |
| لا يعثر Python على llama-server أو ملف GGUF | تحقق من أن `LLAMA_SERVER_EXE` / `GGUF_MODEL_FILE` يشيران إلى ملفات موجودة بالفعل |
| المنفذ مستخدم بالفعل | أوقف الخدمة التي تشغل المنفذ `8000` أو `8001`، أو غيّر المنافذ في Python؛ وعند تغيير `PORT`، حدّث عنوان URL لدى العميل أيضًا |
| تعذر تحميل النموذج | تحقق من دعم إصدار llama.cpp لنموذج PLaMo 3، وتوفر مكتبات تشغيل الواجهة الخلفية، وكفاية ذاكرة RAM / VRAM |
| يعرض المتصفح مشكلة في أذونات الاتصال | تحقق من سماح مدير سكريبتات المستخدم بالوصول إلى العناوين المحلية، ومن أن خدمة Python قيد التشغيل |
| لا يزال Google Translate مستخدمًا | تأكد من تفعيل الترجمة الخارجية وصحة عنوان URL ووجود اللغة المصدر في القائمة المسموح بها؛ وراجع سجل Python وتحذيرات الرجوع إلى الخدمة البديلة في أدوات المطور بالمتصفح |
| الترجمة بلغة هدف غير صحيحة | عدّل `TARGET_LANG` في Python وأعد تشغيل السكريبت، واضبط اللغة الهدف في X Translate أيضًا |
| تُرجع `/translate` رمز الحالة 404 | نقطة النهاية هذه معطّلة افتراضيًا؛ لاستخدامها اضبط `ENABLE_TRANSLATE = True` وأعد تشغيل السكريبت |

تستمع خدمة الربط افتراضيًا إلى العنوان المحلي `127.0.0.1` فقط، ولا تستخدم المصادقة بمفتاح API، وتسمح بالوصول عبر الأصول المختلفة. يُنصح بالإبقاء على عنوان الاستماع المحلي وعدم إتاحة الخدمة مباشرةً على الشبكة المحلية أو الإنترنت. وقد يظهر نص طلبات GET أيضًا في سجلات الوصول المحلية الخاصة بـ HTTP.

## التكامل مع YoutubeLiveChatFlusher

يمكن أيضًا ربط السكريبت نفسه `plamo_flusher_bridge.py` مباشرةً مع [YoutubeLiveChatFlusher](https://github.com/ys-j/YoutubeLiveChatFlusher) (إضافة متصفح لعرض تعليقات YouTube Live فوق الفيديو)، دون الحاجة إلى تشغيل نسخة ثانية من النموذج.

أولًا، فعّل نقطة النهاية ذات اللغة المصدر الثابتة في سكريبت Python:

```python
ENABLE_TRANSLATE = True
SOURCE_LANG = "ja"
TARGET_LANG = "zh-hant"
```

احفظ التغييرات وأعد تشغيل `plamo_flusher_bridge.py`. القيمة الافتراضية الثابتة لـ `SOURCE_LANG` هي اليابانية، وهي مناسبة لتعليقات البث المباشر باللغة اليابانية. يمكنك تعديل `TARGET_LANG` وفقًا لاحتياجاتك، لكن نقطتي النهاية تشتركان في اللغة الهدف نفسها.

في إعدادات **Translator** في YoutubeLiveChatFlusher، اختر **External service**، وفعّل الترجمة واضبط الإعدادات كما يلي:

| الإعداد | القيمة |
| --- | --- |
| Request Method | GET |
| URL | `http://127.0.0.1:8001/translate?q=$q` |
| Response Style | Google Translate |

يمكن تشغيل المشروعين في الوقت نفسه: يستخدم X Translate المسار `/translate-auto` للكشف التلقائي عن اللغة المصدر، بينما يستخدم YoutubeLiveChatFlusher المسار `/translate` بلغة مصدر ثابتة وسياق مستقل لتعليقات البث المباشر. ويشتركان في نموذج PLaMo ومسرد المصطلحات نفسيهما. إذا كنت تستخدم X Translate فقط، فأبقِ `ENABLE_TRANSLATE = False`.
